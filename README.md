# AegisReview AI

AI-powered code security review and vulnerability detection platform.

AegisReview AI helps developers find security vulnerabilities in their source code, understand the risks, and get recommendations for fixing them.

## Features

- Source code security analysis
- Project and repository scanning
- Vulnerability detection
- Line-level security findings
- Severity classification
- AI-powered vulnerability explanations
- Secure-code recommendations
- Security dashboard
- Multi-language support

## Supported Languages

- Python
- JavaScript
- TypeScript
- Java
- C
- C++
- PHP
- Ruby
- Go

## Security Checks

- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection
- Path Traversal
- Hardcoded Secrets
- Insecure Deserialization
- Unsafe Input Handling
- Insecure File Operations
